Application mobile

Accédez à SyLoc depuis votre smartphone : l’interface web est adaptée au mobile. Vous pouvez aussi ajouter SyLoc à l’écran d’accueil pour l’utiliser comme une application dédiée.

Sur votre téléphone
  1. Ouvrez le navigateur (Chrome, Safari, etc.) sur votre smartphone.
  2. Allez à l’adresse : {{ login_url }}
  3. Connectez-vous avec vos identifiants SyLoc.
  4. Vous accédez au même tableau de bord, biens, locataires, baux et loyers qu’en version bureau.
Ajouter SyLoc à l’écran d’accueil

Pour ouvrir SyLoc comme une application (icône sur l’écran d’accueil, sans barre d’adresse) :

  • Sur iPhone (Safari) : touchez le bouton « Partager » (carré avec flèche), puis « Sur l’écran d’accueil ».
  • Sur Android (Chrome) : menu (⋮) → « Ajouter à l’écran d’accueil » ou « Installer l’application ».

Une fois ajouté, l’icône SyLoc apparaît sur votre écran d’accueil et ouvre directement l’application.

L’application mobile Premium vous permet de consulter et gérer vos biens, locataires, baux et loyers où que vous soyez.
