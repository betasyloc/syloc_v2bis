Pour relancer SyLoc après avoir tout fermé :

1. Ouvrir un terminal

Dans Cursor : Terminal → Nouveau terminal (ou Ctrl+ù)
Ou PowerShell / Invite de commandes Windows
2. Aller dans le dossier du projet => cd C:\Users\papem\immo_saas
3. Activer l’environnement virtuel => .venv\Scripts\Activate
(Le préfixe (.venv) doit apparaître dans le terminal.)
4. Démarrer le serveur Django => python manage.py runserver
5. Ouvrir l’application => Dans le navigateur : http://127.0.0.1:8000/ (ou le lien affiché dans le terminal).
En une seule commande (depuis n’importe quel dossier) : => cd C:\Users\papem\immo_saas; .venv\Scripts\Activate; python manage.py runserver
Pour arrêter le serveur : Ctrl+C dans le terminal.
