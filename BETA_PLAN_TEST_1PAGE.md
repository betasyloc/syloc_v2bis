# SyLoc - Beta test (version courte)

## Objectif

Valider que SyLoc est simple, fiable et utilisable en conditions reelles (desktop + mobile) avant ouverture plus large.

## Duree

- 2 semaines
- Temps recommande par testeur: 30 a 60 min

## Parcours a tester (priorite)

1. Inscription / Connexion
- Creer un compte basic
- Creer un compte Premium
- Verifier que le choix de formule est bien conserve

2. Gestion locative
- Creer/modifier/supprimer un bien
- Creer/modifier/supprimer un locataire
- Creer/modifier/supprimer un bail

3. Loyers / Quittances
- Marquer un loyer comme paye
- Telecharger une quittance PDF

4. Equipe
- Ajouter un membre a l'equipe
- Verifier partage des donnees entre membres

5. Portail locataire
- Ouvrir le lien locataire
- Verifier que le locataire accede uniquement a:
  - son bail
  - ses quittances
- Verifier le bouton "Quitter le mode locataire"

6. Mobile
- Tester connexion, navigation et formulaires sur smartphone

## Comment remonter un bug (format)

Merci d'envoyer:

- Page/fonction concernee
- Etapes pour reproduire
- Resultat obtenu
- Resultat attendu
- Capture ecran/video
- Niveau d'impact:
  - P0 Bloquant
  - P1 Majeur
  - P2 Mineur
  - P3 Cosmétique

## Definition de "pret"

La beta est consideree validee si:

- 0 bug P0 ouvert
- P1 corriges (ou planifies avec date)
- > 90% des parcours ci-dessus passent
